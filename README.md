# LEDUC - Site Institucional

Site institucional desenvolvido para a LEDUC - Soluções em Segurança do Trabalho.

## Sobre o projeto

O projeto apresenta os principais serviços e treinamentos oferecidos pela LEDUC, com foco em segurança do trabalho, prevenção de riscos e contato comercial.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do site

- Página inicial
- Serviços
- Treinamentos
- Galeria
- Contato
- Integração com WhatsApp

## Status

Projeto em desenvolvimento.
